# AI-Powered Crop Disease Detection and Agrochemical Recommendation Framework

An AI-powered web application that detects tomato leaf conditions from images and provides agrochemical and crop-management guidance.

## 🚀 Live Demo

[Try AgroDisease AI](https://agrodisease-ai-proj-git-531039-spandana-basava-kulal-s-projects.vercel.app/)

## ✨ Features

- Tomato leaf condition detection
- AI confidence prediction
- Agrochemical recommendation
- Crop-management guidance
- FastAPI REST API
- Cloud deployment

## 🧠 AI Model

- **Model:** EfficientNetB0
- **Input Size:** 224 × 224
- **Classes:** 4
  - Healthy Leaves
  - Dried Leaves
  - Leaves with Stains
  - Leaves with Yellow Stains

## 📊 Model Performance

- Accuracy: **92%**
- Precision: **92.41%**
- Recall: **92.82%**
- F1-Score: **91.83%**
